# ZERO — обратный отсчёт

Android-приложение: список событий с обратным отсчётом (карточки или плитки), напоминания заранее и в момент наступления, виджеты на рабочий стол.

- Сборка APK — GitHub Actions при каждом push в `main`, файл появляется в Releases.
- Локально: `npm ci && npm run build && npm test`, просмотр в браузере — `npm run dev`.
- Код интерфейса: `src/js`, `src/css` (склеиваются по порядку имён); натив: `native/android`.
